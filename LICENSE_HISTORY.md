# BrainC License History

## Proprietary era

BrainC was originally maintained as proprietary software under an all-rights-reserved license.

The exact pre-Phi-Commons state is preserved at:

```text
archive/pre-phi-commons-license-2026-09-17
```

Commit:

```text
4a773a5c58779552a6ea4b3e1ce64eaff9c1fc1f
```

The historical proprietary license remains visible in that preserved branch and in Git history.

## Phi Commons / MIT era

Beginning with the Phi Commons migration, project-owned BrainC code and documentation are released under the MIT License unless otherwise noted.

Third-party packages, external services, model weights, datasets, and upstream images remain under their respective terms.

## Provenance rule

The licensing transition is additive history, not a rewrite of history.
